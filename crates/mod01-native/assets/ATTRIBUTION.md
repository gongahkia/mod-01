# Native Studio visual assets

- `bigblue/BigBlue_TerminalPlus.ttf` is BigBlue Terminal Plus by VileR, from the
  [BigBlue Terminal source](https://int10h.org/blog/2015/12/bigblue-terminal-oldschool-fixed-width-font/)
  via the [Nerd Fonts unpatched source tree](https://github.com/ryanoasis/nerd-fonts/tree/master/src/unpatched-fonts/BigBlueTerminal).
  It is licensed under Creative Commons Attribution-ShareAlike 4.0; the complete
  license is preserved in `bigblue/LICENSE.TXT`. No font outlines were changed.
- `kenney/tile_*.png` are from [Kenney's Cursor Pixel Pack](https://kenney.nl/assets/cursor-pixel-pack),
  licensed under CC0. The original license text is in `kenney/License.txt`.

Both sets are embedded locally in the native executable. No asset is fetched at runtime.
