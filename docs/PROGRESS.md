# Implementation status

The current native-only scope, per-feature acceptance criteria and completion
evidence are tracked in [NATIVE_IMPLEMENTATION.md](NATIVE_IMPLEMENTATION.md).
Git history retains earlier implementation checkpoints; they are not alternate
supported hardware, authoring formats or browser products.

The source of truth is one M01W/2 workcart, packed as M01C/2 for one machine.
See [README](../README.md) to run it, [STUDIO.md](STUDIO.md) for native tools,
[TOOLS.md](TOOLS.md) for CLI operations, and [HARDWARE.md](HARDWARE.md) for the
current device contract. Native visual QA and all unchecked acceptance rows
remain open.
